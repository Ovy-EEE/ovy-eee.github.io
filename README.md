# Sanwar Ahmed Ovy — Academic & Silicon Engineering Portfolio

An interactive, modern portfolio for **Sanwar Ahmed Ovy**, Ph.D. student in Electrical and Computer Engineering at North Dakota State University (NDSU) and EEE graduate from Bangladesh University of Engineering and Technology (BUET).

Designed with a high-tech dark mode aesthetic featuring glowing circuit board traces, microchip patterns, and subtle floating mathematical formulas honoring nearly 10 years of competitive Math Olympiad championships.

---

## 🔬 Core Highlights & Features

- **High-Tech Aesthetic**: Dark-mode canvas with dynamic circuit board traces, glowing electric pulses, and floating mathematical formula animations ($\int e^{-x^2}dx$, $e^{i\pi}+1=0$, $\nabla \times \mathbf{B}$, etc.).
- **Hero & Career Vision**: Prominent spotlight on his ultimate career vision: **working in the chip-manufacturing industry**, backed by GSAP entrance choreography, academic credentials (NDSU GRA, BUET EEE), and real-time die specifications.
- **Interactive Research Grid**: Glowing modular cards detailing core focus areas:
  - **Fabrication**: Triple-Frequency Capacitive RF Sheath and Ion Energy Distribution (IED) modeling for controllable etching.
  - **VLSI**: 3:1 Configurable Logic Block (CLB) unit, transistor sizing, SRAM memory layout in Cadence Virtuoso.
  - **FPGA**: Reconfigurable hardware, finite-state machine (FSM) syntheses, and Verilog HDL.
  - **Machine Learning**: Emerging technology-based circuit architectures (Next Generation System Design Lab) and DSP drowsiness detection.
- **Animated Vertical Timeline**: Chronological tracking from BUET B.Sc. in EEE to NDSU doctoral studies, including GRE (Quantitative 167/170, ~90th percentile) and IELTS (Band 8.0) performance.
- **Academic Projects Showcase**: Filterable grid and featured spotlights for all 13 BUET lab projects, notably:
  - *Optoelectronic Integrated Circuit (OEIC)*
  - *Smart Traffic Control System (Verilog & Cadence)*
  - *Configurable Logic Block (CLB in Cadence Virtuoso)*
  - *Logic IC Tester (STM32 & Proteus)*
  - Interactive project detail modal with engineering milestones and toolchain tags.
- **Celebratory Awards Section**: Visually festive section honoring his **National Math Olympiad Championship (2015)**, **5 Consecutive Regional Championships (Perfect Scorer in 2016)**, **National Podiums**, and **Government Board Merit Scholarships (HSC & SSC)** with interactive particle confetti.
- **Interactive Silicon Workbench**: Hands-on simulator allowing visitors to toggle inputs on a **3:1 CLB unit**, step through the **Verilog Traffic FSM**, and diagnose IC gates in the **STM32 Logic Tester**.
- **Comprehensive Skills & Toolchains**: Structured display of EDA suites (Cadence Virtuoso, Quartus II, Proteus, STM32CubeIDE), programming languages, physical testbench hardware (Oscilloscope, PLC, ANACOM), and languages.
- **Academic Supervision & Reference**: Official contact information for PhD supervisor **Dr. Sumitha George** (NDSU) and direct contact form.

## 🛠️ Tech Stack

- **Framework**: [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/) with custom silicon glassmorphism and neon glows
- **Animations**: [GSAP](https://greensock.com/gsap/) & Canvas API
- **Celebration Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Typography**: Inter & JetBrains Mono

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Visit `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
